# Exam STEM CR
Prototipo estático independiente, sin Python ni servidor. Subir los archivos de esta carpeta a la raíz de un repositorio GitHub. En Settings → Pages → Deploy from a branch → main / (root). Abrir index.html localmente para probar.

Incluye nueve temas iniciales, cuatro tipos de ítem, puntajes, encabezado, edición, soluciones, impresión/PDF del navegador y descarga LaTeX. Seleccionar el tamaño correspondiente también en el diálogo de impresión; desactivar encabezados del navegador si procede. LaTeX se compila externamente. Los temas no constituyen una cobertura curricular completa; identificación y desarrollo reutilizan plantillas iniciales y requieren revisión docente. Los bancos pequeños rechazan cantidades superiores a las preguntas distintas disponibles. Editar una pregunta no recalcula su solución: revisar y editar ambas. No incluye cuentas, Word, folleto, escudos ni tabla de especificaciones. La configuración se guarda localmente, no los exámenes. No publicar datos personales. Para uso comercial revisar condiciones del alojamiento.
