# Exam STEM CR 2.0
Aplicación estática en español. Subir index.html, app.js y style.css a la raíz de un repositorio y activar GitHub Pages (main / root). No requiere Python, servidor ni API.

Generar un examen, editar preguntas, alternativas (3/4), respuestas, puntajes, incisos, rúbricas, figuras y espacios. Los indicadores de rúbrica sustituyen el puntaje del ítem cuando existen. Mover preguntas dentro de su sección. Guardar/recuperar un examen en el navegador. Imprimir en carta, legal, oficio o doble carta; elegir el mismo tamaño en el diálogo de impresión. Mostrar soluciones antes de imprimir para obtener el solucionario. El editor LaTeX descarga código para compilar externamente; las figuras se insertan manualmente y la maquetación no es idéntica al HTML. No hay compilador integrado ni folleto automático. Banco inicial limitado a nueve temas; nivel es metadato, no filtro pedagógico. Revisar las preguntas manuales y rúbricas antes de publicar. No guardar datos sensibles de estudiantes. GitHub Pages tiene restricciones de uso comercial.
